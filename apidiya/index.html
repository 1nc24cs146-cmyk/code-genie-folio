ApiDiya

A light that shows whether an API works. A Postman-style testing workspace for VS Code and Antigravity — requests, collections, test suites and a local mock server, with no cloud and no account.

Install on Antigravity (Open VSX) View source on GitHub

— downloads on Open VSX · Latest version 0.2.1

🚀 Send any request

GET, POST, PUT, PATCH and DELETE, with headers, query params, JSON/raw bodies and Bearer, API key or Basic auth.

📁 Collections & environments

Organise requests into collections and switch environments with {{baseUrl}} variable substitution.

✅ Test suites & assertions

Check status, response time, JSON values, headers and body content — evaluated as data, never as a script. Generate starter assertions from a real response.

🔄 Import & export

Import Postman v2.1 JSON, OpenAPI 3 JSON or ApiDiya JSON. Export any collection as ApiDiya JSON.

🧪 Local mock server

Define method + path + status + body mocks and serve them on your own machine (default port 3101) — unmatched paths return 404.

🕘 History

Every request is logged with method, URL, status, duration and time, and can be re-run in one click.

Install

  1. Open VS Code or Antigravity.
  2. Open Extensions, search ApiDiya, and install it — or use … → Install from VSIX… with a VSIX from the GitHub repo.
  3. Click the ApiDiya icon in the activity bar, or run ApiDiya: Open from the Command Palette.

Privacy — stored on your device only

Collections, environments, test suites, test runs, mocks and history are stored in the editor’s local storage on your device only. ApiDiya never uploads them to a cloud, and there is no telemetry or analytics.

Saved auth tokens and API keys live in your operating system’s keychain (VS Code SecretStorage), not in stored requests or history — history shows only ***.

The only network traffic is the request you press Send/Run on, sent to the URL you typed, plus the local mock server on your own machine.

Not yet included

  • A full MCP server and AI-model test generation — planned next, not claimed here.
  • Team sharing or cloud sync — deliberately not included; everything stays local.
