01 — FEATURES

What it does

One sidebar for requests, collections, environments, suites, mocks, and history — with secrets kept out of stored data.

Send any request

GET, POST, PUT, PATCH and DELETE, with headers, query params, JSON/raw bodies and Bearer, API key or Basic auth.

Collections & environments

Organise requests into collections and switch environments with {{baseUrl}} variable substitution.

Test suites & assertions

Check status, response time, JSON values, headers and body content — evaluated as data, never as a script. Generate starter assertions from a real response.

Import & export

Import Postman v2.1 JSON, OpenAPI 3 JSON or ApiDiya JSON. Export any collection as ApiDiya JSON.

Local mock server

Define method + path + status + body mocks and serve them on your own machine (default port 3101) — unmatched paths return 404.

History

Every request is logged with method, URL, status, duration and time, and can be re-run in one click.

Download count, visible in the extension

Antigravity's own extension-details panel has no downloads row, so ApiDiya shows its live Open VSX download count at the top of its own sidebar panel, from version 0.2.2.

02 — INSTALL

Three steps, then send

  1. 1

    Install it

    Open the Open VSX page for ApiDiya and install it, or in VS Code or Antigravity go to Extensions → … → Install from VSIX and choose the VSIX file.

  2. 2

    Open the sidebar

    Click the ApiDiya icon in the activity bar, or run ApiDiya: Open from the Command Palette.

  3. 3

    Send your first request

    Pick a seeded request or type your own URL, press Send, then save it to a collection or add assertions and run it as a test.

No account, no API key, and no model needed. The store's current published version is 0.2.1 — the 0.2.2 sidebar download count is in the VSIX builds, and appears on the store once 0.2.2 is published there.

03 — PRIVACY

Stored on your device only

Collections, environments, test suites, test runs, mocks and history live in the editor's local storage on your device only. ApiDiya never uploads them to a cloud, and there is no telemetry or analytics.

Secrets in the keychain

Saved auth tokens and API keys live in your operating system's keychain (VS Code SecretStorage), not in stored requests or history — history shows only ***.

No sync, by design

ApiDiya never marks data for Settings Sync, so local storage is never uploaded to a cloud account.

One network call: yours

The only network traffic is the request you press Send/Run on, sent to the URL you typed, plus the local mock server on your own machine.

04 — HONEST LIMITS

What it does not do

No full MCP server and no AI-model test generation yet — planned next, not claimed here. No team sharing or cloud sync — deliberately not included; everything stays local.
